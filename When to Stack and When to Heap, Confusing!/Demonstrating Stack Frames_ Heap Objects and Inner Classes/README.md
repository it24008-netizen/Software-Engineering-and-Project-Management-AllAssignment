# Demonstrating Stack Frames, Heap Objects, and Inner Classes

## Run
Compile and run `src/Main.java` using IntelliJ IDEA, or from the project folder:

```bash
javac src/Main.java
java -cp src Main
```

Example input:
- Salary: `30000`
- Bonus: `5000`

Identity hash codes may differ each run and are not actual memory addresses.
